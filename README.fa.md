# ‏SOLO Panel: پنل رایگان و خودمیزبان VPN برای Railway ‏(Xray-core، VLESS، Trojan)

‏**SOLO Panel** یک **پنل VPN / پروکسی** متن‌باز و خودمیزبان است که با چند کلیک روی [Railway](https://railway.com) مستقر می‌شود. این پنل [Xray-core](https://github.com/XTLS/Xray-core) را برای شما اجرا می‌کند، اتصال‌های **VLESS** و **Trojan** را خودکار می‌سازد و **یک لینک اشتراک** (Subscription) به شما می‌دهد تا آن را در برنامهٔ VPN گوشی یا رایانهٔ خود وارد کنید.

بدون VPS، بدون دستورهای لینوکسی، بدون نصب پایگاه داده و بدون فایل پیکربندی دستی.

**کلیدواژه‌ها:** پنل VPN، پنل پروکسی، پنل Xray، VLESS، Trojan، WebSocket، XHTTP، HTTP Upgrade، لینک اشتراک، استقرار روی Railway، VPN خودمیزبان، Node.js، متن‌باز.

<a id="what-is"></a>

## ‏SOLO Panel چیست؟

پنل VPN یک وب‌سایت کوچک است که یک سرور VPN را کنترل می‌کند. وارد آن می‌شوید و اتصال‌هایی را می‌بینید که برنامه‌های VPN شما می‌توانند از آن‌ها استفاده کنند.

‏SOLO Panel سه کار برایتان انجام می‌دهد:

1. **موتور VPN** (Xray-core) را داخل پروژهٔ Railway شما اجرا می‌کند.
2. **همهٔ اتصال‌ها را خودکار می‌سازد:** پروتکل‌ها و انتقال‌های (Transport) مختلف، تا اگر یکی از کار افتاد، جایگزین داشته باشید.
3. **یک لینک اشتراک واحد می‌دهد.** آن را در برنامهٔ VPN وارد کنید تا همهٔ اتصال‌ها یک‌جا و با نام `Solo-Panel` اضافه شوند.

<a id="who-for"></a>

## برای چه کسانی است؟

- کسانی که **VPN خصوصی خودشان** را می‌خواهند، بدون اجاره و مدیریت سرور.
- مبتدیانی که تا به حال پروکسی راه‌اندازی نکرده‌اند.
- هر کسی که از قبل از Railway استفاده می‌کند و پنل آمادهٔ Xray می‌خواهد.

<a id="features"></a>

## ویژگی‌ها

- **استقرار با یک کلیک** روی Railway: مخزن را Fork کنید و مستقر کنید.
- **بدون نیاز به پیکربندی:** بدون هیچ تنظیمی کار می‌کند.
- **اتصال‌های خودکار:** VLESS و Trojan روی WebSocket، XHTTP و HTTP Upgrade، با چند اثرانگشت TLS و گزینهٔ ALPN.
- **یک لینک اشتراک** که در برنامه‌های VPN کار می‌کند و در مرورگر معمولی یک صفحهٔ وضعیت خوانا نشان می‌دهد.
- **کلیدهای حالت:** پروتکل‌ها، انتقال‌ها، مقادیر ALPN یا اثرانگشت‌ها را از داشبورد روشن یا خاموش کنید.
- **محدودیت زمان و حجم:** تاریخ پایان و سقف حجم تعیین کنید؛ داشبورد و بسیاری از برنامه‌های VPN مقدار باقی‌مانده را نشان می‌دهند.
- **پایش سلامت و بازیابی خودکار:** پنل همهٔ اتصال‌ها را بررسی می‌کند و اگر موتور گیر کند، آن را راه‌اندازی مجدد می‌کند.
- **ورود فقط با گذرواژه** برای مدیر، همراه با محافظت CSRF.
- **داشبورد سازگار با موبایل.**

<a id="quick-start"></a>

## شروع سریع: استقرار در ۴ گام

به یک حساب رایگان [GitHub](https://github.com) و یک حساب [Railway](https://railway.com) نیاز دارید. نیازی به برنامه‌نویسی نیست.

### گام ۱ - استقرار روی Railway

1. این مخزن را **Fork** کنید (دکمهٔ *Fork* در بالای همین صفحه).
2. در Railway روی **New Project ← Deploy from GitHub repo** کلیک کنید و Fork خود را انتخاب کنید.
3. ‏Railway خودش پنل را می‌سازد و اجرا می‌کند (Node 20، با Nixpacks). صبر کنید تا استقرار موفق نشان داده شود.

### گام ۲ - افزودن حافظهٔ دائمی (مهم!)

بدون این گام، **با هر استقرار مجدد، گذرواژهٔ مدیر و همهٔ اتصال‌های ساخته‌شده پاک می‌شود** و باید از اول شروع کنید.

1. در سرویس Railway خود کلیدهای `Ctrl+K` (در مک `⌘K`) را بزنید تا **Command Palette** باز شود، عبارت **volume** را جست‌وجو کنید و **New Volume** را انتخاب کنید. (روش دیگر: روی سرویس در بوم کلیک راست کنید ← **Attach Volume**.)
2. وقتی **مسیر اتصال** (mount path) را خواستند، این را وارد کنید:

   ```
   /app/data
   ```

3. سرویس را **دوباره مستقر (Redeploy)** کنید تا تغییر اعمال شود.

### گام ۳ - ورود و تغییر گذرواژهٔ مدیر

**گذرواژهٔ پیش‌فرض پنل `admin` است.** نام کاربری وجود ندارد و فقط گذرواژه لازم است. چون هر کسی که نشانی شما را پیدا کند می‌تواند آن را امتحان کند، بلافاصله پس از اولین ورود آن را تغییر دهید.

**گزینهٔ الف - تغییر در پنل (ساده‌ترین، در هر زمان):** با `admin` وارد شوید و از گزینهٔ **تغییر گذرواژه** در داشبورد استفاده کنید. از حساب خارج می‌شوید و می‌توانید با گذرواژهٔ جدید وارد شوید.

**گزینهٔ ب - تنظیم پیش از اولین راه‌اندازی:**

1. در Railway سرویس خود را باز کنید ← **Variables** ← **New Variable**.
2. ‏**Name:** ‎`ADMIN_PASSWORD` - **Value:** گذرواژهٔ دلخواه شما.
3. ‏**Redeploy** کنید.

> ⚠️ متغیر `ADMIN_PASSWORD` فقط *بار اول* خوانده می‌شود، یعنی پیش از آنکه حساب مدیر ساخته شود. اگر پنل قبلاً یک بار اجرا شده است، از گزینهٔ الف استفاده کنید.

### گام ۴ - باز کردن پنل

نشانی عمومی سرویس Railway خود (مثلاً `https://your-app.up.railway.app`) را در مرورگر باز کنید و وارد شوید. در داشبورد، **Subscription URL** را کپی کنید.

همین کافی است. هر آنچه در ادامه آمده اختیاری و صرفاً برای آشنایی بیشتر است.

<a id="how-to-use"></a>

## نحوهٔ استفاده از VPN

1. ‏**Subscription URL** را از داشبورد کپی کنید.
2. برنامهٔ VPN خود را باز کنید و یک **اشتراک** (گاهی با نام *subscription link*، *import from URL* یا *add profile from link*) اضافه کنید. نشانی را جای‌گذاری کنید.
3. اشتراک را به‌روزرسانی کنید. اتصال‌ها با نام `Solo-Panel` در برنامه ظاهر می‌شوند.
4. یک اتصال را انتخاب کنید و متصل شوید.

برنامه‌های سازگار عبارت‌اند از v2rayNG، v2rayN، Hiddify، Happ، NekoBox، Streisand و هر برنامهٔ دیگری که از لینک‌های اشتراک استاندارد پشتیبانی کند. اگر یک اتصال روی شبکهٔ شما کار نکرد، اتصال دیگری را امتحان کنید.

اگر همین نشانی را در مرورگر معمولی باز کنید، به‌جای آن یک صفحهٔ وضعیت نمایش داده می‌شود: سلامت اتصال‌ها، زمان باقی‌مانده و حجم باقی‌مانده.

<a id="glossary"></a>

## واژه‌نامهٔ ساده

| اصطلاح | معنی به زبان ساده |
| ------ | ----------------- |
| ‏**VPN / پروکسی** | سرویسی که ترافیک اینترنت شما را از طریق سرور دیگری عبور می‌دهد. |
| ‏**Railway** | پلتفرم میزبانی که بدون مدیریت سرور می‌توانید برنامه روی آن اجرا کنید. |
| ‏**Xray-core** | موتور متن‌باز که ترافیک VPN شما را واقعاً حمل می‌کند. SOLO Panel آن را راه‌اندازی و کنترل می‌کند. |
| ‏**VLESS، Trojan** | دو پروتکل VPN؛ یعنی «زبان‌های» متفاوت میان برنامهٔ شما و سرور. |
| ‏**WebSocket، XHTTP، HTTP Upgrade** | روش‌هایی برای حمل آن ترافیک، طوری که شبیه ترافیک عادی وب به نظر برسد. |
| ‏**ALPN، اثرانگشت TLS** | جزئیات کوچکی از نحوهٔ شروع اتصال امن توسط برنامهٔ شما. مقادیر مختلف وقتی یکی مسدود شود کمک می‌کنند. |
| **لینک اشتراک** | یک نشانی که فهرست کاملی از اتصال‌ها را به برنامهٔ VPN شما می‌دهد و آن را به‌روز نگه می‌دارد. |
| ‏**Volume** | حافظهٔ دائمی در Railway تا داده‌هایتان پس از استقرار مجدد باقی بماند. |

<a id="settings"></a>

## تنظیمات (متغیرهای محیطی)

همه‌چیز اختیاری است و پنل بدون هیچ‌کدام از این‌ها اجرا می‌شود. در Railway آن‌ها را در سرویس خود ← **Variables** اضافه کنید.

| متغیر | پیش‌فرض | کاربرد |
| ----- | ------- | ------ |
| ‏`ADMIN_PASSWORD` | ‏`admin` | گذرواژهٔ مدیر. فقط در اولین راه‌اندازی پنل استفاده می‌شود. |
| ‏`NODE_ENV` | تنظیم‌نشده | برای کوکی‌های نشست امن (فقط HTTPS) روی `production` بگذارید. |
| ‏`SESSION_SECRET` | تولید خودکار | فقط اگر به یک مقدار ثابت مشترک میان چند نمونه نیاز دارید تنظیم کنید. |
| ‏`DATA_DIR` | مسیر اتصال Volume شما، یا `./data` در نبود آن | محل ذخیرهٔ داده‌ها. فقط اگر از Railway Volume استفاده نمی‌کنید خودتان تنظیم کنید. |
| ‏`XRAY_VERSION` | آخرین نسخهٔ منتشرشده در زمان نصب | برای ساخت‌های تکرارپذیر، نسخهٔ مشخصی از Xray-core را ثابت کنید. |
| ‏`PUBLIC_DOMAIN` | تنظیم‌نشده | دامنهٔ جایگزین برای لینک‌ها. لینک‌ها معمولاً با دامنه‌ای که واقعاً باز می‌کنید یکی هستند. |

متغیرهای `RAILWAY_PUBLIC_DOMAIN` و `RAILWAY_REPLICA_REGION` را Railway خودکار تنظیم می‌کند و نیازی به دست‌زدن به آن‌ها نیست.

<a id="faq"></a>

## پرسش‌های متداول

### آیا SOLO Panel رایگان است؟
خود SOLO Panel رایگان و متن‌باز است (مجوز MIT). Railway قیمت‌گذاری و قوانین دورهٔ آزمایشی خودش را دارد؛ برای هزینهٔ مصرف خود به سایت آن‌ها مراجعه کنید.

### آیا به VPS یا نام دامنه نیاز دارم؟
خیر. Railway سرور و یک نشانی عمومی HTTPS در اختیارتان می‌گذارد. در صورت تمایل می‌توانید دامنهٔ اختصاصی خودتان را هم در Railway متصل کنید.

### چگونه VPN را به گوشی‌ام اضافه کنم؟
‏**Subscription URL** را از داشبورد کپی کنید و در یک برنامهٔ VPN مانند v2rayNG ‏(اندروید)، Streisand ‏(آیفون) یا Hiddify به‌عنوان اشتراک اضافه کنید. بخش [نحوهٔ استفاده از VPN](#how-to-use) را ببینید.

### گذرواژهٔ پیش‌فرض چیست و آیا می‌توانم آن را تغییر دهم؟
گذرواژهٔ پیش‌فرض پنل `admin` است. پس از ورود می‌توانید هر زمان آن را از داشبورد تغییر دهید. [گام ۳](#quick-start) را ببینید.

### چرا گذرواژهٔ مدیر ریست شد؟
‏Railway Volume متصل نکرده‌اید، بنابراین حافظه با استقرار مجدد پاک شده است. [گام ۲](#quick-start) را ببینید.

### آیا می‌توانم مدت یا حجم استفاده از VPN را محدود کنم؟
بله. در داشبورد تاریخ پایان و سقف حجم تعیین کنید. برای نامحدود، آن‌ها را خالی بگذارید. این محدودیت‌ها به شما و در بسیاری از برنامه‌های VPN نمایش داده می‌شوند، اما صرفاً اطلاع‌رسانی هستند؛ به [محدودیت‌های شناخته‌شده](#limitations) نگاه کنید.

### چرا با تغییر یک تنظیم، اتصال قطع می‌شود؟
تغییر پروتکل‌ها یا انتقال‌های فعال، موتور VPN را راه‌اندازی مجدد می‌کند و همه برای مدت کوتاهی قطع می‌شوند. اگر فقط محدودیت‌ها را تغییر دهید، چیزی راه‌اندازی مجدد نمی‌شود.

### از کدام پروتکل‌های VPN پشتیبانی می‌کند؟
‏VLESS و Trojan، روی WebSocket، XHTTP و HTTP Upgrade، که همه از طریق تنها پورت امن HTTPS در Railway سرویس داده می‌شوند.

<a id="limitations"></a>

## محدودیت‌های شناخته‌شده

- **محدودیت‌ها صرفاً اطلاع‌رسانی هستند.** داشبورد «چند روز / چند گیگابایت باقی مانده» را نشان می‌دهد، اما با رسیدن به سقف، ترافیک مسدود نمی‌شود.
- **تغییر حالت‌های اتصال برای مدت کوتاهی همه را قطع می‌کند،** زیرا موتور پروکسی راه‌اندازی مجدد می‌شود.
- **فراموشی گذرواژه.** `ADMIN_PASSWORD` فقط در اولین راه‌اندازی اعمال می‌شود. اگر گذرواژه را فراموش کنید و نتوانید وارد شوید، باید حافظه را پاک کنید و از اول شروع کنید که اتصال‌های ساخته‌شده را هم ریست می‌کند.
- **فقط لینوکس.** موتور پروکسی روی ویندوز اجرا نمی‌شود. با WSL یا لینوکس آزمایش کنید، یا ساده‌تر، روی Railway مستقر کنید.

<a id="run-local"></a>

## اجرا روی رایانهٔ شخصی

فقط برای توسعه‌دهندگان؛ برای استفاده از پنل روی Railway به این بخش نیازی ندارید.

<div dir="ltr" align="left">

```bash
cp .env.example .env   # edit as needed; everything in it is optional
npm install             # also downloads the Xray-core engine
npm start
```

</div>

سپس `http://localhost:3000` را باز کنید. روی ویندوز رابط مدیریت کار می‌کند اما موتور پروکسی اجرا نمی‌شود؛ بنابراین از WSL/لینوکس استفاده کنید یا روی Railway آزمایش کنید.
